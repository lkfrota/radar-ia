Como a Clay constrói agentes GTM com Jeff Barg

Latent Space

A Clay quer que os usuários obtenham resultados semelhantes tanto usando seu próprio agente quanto apontando ferramentas de programação externa, como o Claude Code, para a plataforma. O uso já se divide quase meio a meio entre o agente próprio e ferramentas externas.

Jeff Barg, Head de IA (líder de inteligência artificial) na Clay, aponta que a empresa cresceu de 50 para 600 funcionários após captações milionárias. O custo para cruzar milhões de empresas com perfis de clientes ideais usando classificadores modernos é baixo, mas o real valor está no uso de modelos de ponta para orquestração e pesquisa profunda.

O primeiro projeto de Jeff, chamado Sculptor, rodava ferramentas em loop, mas era ineficiente para tarefas complexas como agendar reuniões. A experiência mostrou que agentes de código se dão muito bem com comandos em Bash e scripts em Python.

A infraestrutura de agentes da Clay continua rodando em um sistema próprio construído com BullMQ, dispensando frameworks complexos adicionais. Isso evidencia que abordagens diretas e enxutas funcionam muito bem na engenharia de software aplicada a IAs.

Google exigirá servidores MCP para agentes de IA

Hacker News (descoberta)

O Google tornou seus servidores MCP (Model Context Protocol, um protocolo padrão para conectar IAs a fontes de dados) do Google Workspace disponíveis para o público, publicando novas regras de termos de API.

A partir de fevereiro de 2027, qualquer agente de IA que acesse ferramentas como Gmail, Drive e Calendar precisará obrigatoriamente passar por esses servidores específicos do Google, sob pena de restrição ou suspensão de conta.

O servidor MCP do Gmail possui limitações estritas: ele permite ler e buscar mensagens, mas não consegue enviar, responder ou encaminhar e-mails sem acesso de parceiro especial. Além disso, APIs REST diretas para IA terão cotas severamente reduzidas.

A nova política também impõe regras rígidas de dados, proibindo o uso de informações do Workspace para treinamento, ajuste fino (fine-tuning) ou construção de produtos concorrentes, além de limitar a retenção de dados a 30 dias.

OS-Omni: Benchmark para avaliar agentes de computador de uso geral

Hugging Face Papers (descoberta)

Agentes operando computadores precisam cada vez mais concluir fluxos de trabalho realistas em vez de apenas executar ações isoladas na interface gráfica (GUI).

Para testar isso, pesquisadores introduziram o OS-Omni, um ambiente de avaliação para computadores que abrange sistemas como Windows, Ubuntu, macOS, iOS, Android e a Web.

O benchmark v1 inclui dezenas de tarefas por plataforma e fluxos de trabalho que combinam desktops com celulares. Tarefas complexas exigem dezenas de passos de interação humana e rastreamento de estado persistente.

Os testes mostram que os melhores modelos de IA atuais atingem cerca de 68% de sucesso, ficando atrás de humanos e demonstrando dificuldade em manter o desempenho robusto em múltiplos sistemas operacionais de longo prazo.

Resolver visão com código: Agentes superam modelos de vídeo tradicionais

Hugging Face Papers (descoberta)

Modelos de geração de vídeo costumam ser avaliados como razonadores visuais, gerando vídeos quadro a quadro a partir de um comando textual e uma imagem inicial.

Pesquisadores testaram uma alternativa simbólica: em vez de processar pixels diretamente, um agente de programação escreve um programa de computador que renderiza o vídeo correto.

Em testes rigorosos em suítes de raciocínio cognitivo, agentes de código baseados em modelos avançados superaram significativamente os melhores modelos de vídeo tradicionais.

Isso demonstra que, para tarefas cujas soluções podem ser calculadas a partir de uma imagem inicial, a síntese de programas via código é uma rota muito mais confiável do que a geração direta de pixels.

Hugging Face Papers (descoberta)

Swarms: Como construir, treinar e avaliar sistemas multiagentes

Hugging Face Blog

A construção de sistemas multiagentes (agentes de IA que operam em grupo, chamados de swarms) é um campo desafiador e em expansão na engenharia de software.

Adicionar múltiplos agentes altera o contexto, o orçamento computacional e a complexidade do sistema. A comunicação entre eles não gera melhorias automáticas de desempenho sem treinamento adequado.

Uma série prática de artigos comunitários busca explorar esses problemas na prática, treinando pequenos grupos de agentes em tarefas verificáveis usando infraestruturas em nuvem acessíveis.

Casos recentes demonstraram o potencial de grandes grupos de agentes lidando com problemas matemáticos complexos, mas também evidenciaram falhas de isolamento onde agentes interagiram de forma não prevista.

Building on Nemotron 3.5 Parse: Open Data, Fine-Tuning, and Faster Inference

Hugging Face Blog

A NVIDIA lançou atualizações para o Nemotron 3.5 Parse, um modelo compacto projetado para extrair dados estruturados de imagens de documentos. Essa tecnologia converte páginas impressas ou digitais em uma ordem de leitura lógica, identificando títulos, tabelas e gráficos, o que facilita o uso em sistemas de busca e agentes de inteligência artificial.

Para melhorar a precisão na leitura de gráficos sem valores numéricos explícitos e tabelas complexas, a desenvolvedora utilizou dados sintéticos. Foram abertos três grandes conjuntos de dados de treinamento, incluindo milhões de exemplos de gráficos e tabelas renderizados artificialmente, além de materiais para reconhecimento ótico de caracteres (OCR, tecnologia que converte imagens de texto em texto editável por computador).

Running the full server-side Datasette Python app in the browser with service workers and Pyodide

Simon Willison

O Datasette Lite é uma adaptação da aplicação em Python chamada Datasette para rodar diretamente no navegador web, utilizando tecnologias como WebAssembly (tecnologia para executar código de alta performance em navegadores) e Pyodide (um interpretador Python compilado para o navegador).

A nova versão utiliza service workers (scripts executados em segundo plano no navegador) para entregar uma experiência quase idêntica à de um servidor real. Isso permite navegar por bancos de dados SQLite e arquivos CSV, além de instalar plugins visuais diretamente pela URL sem a necessidade de configurar um servidor web dedicado.
